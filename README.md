# AutoTntCart

One-click instant TNT minecart trick for Fabric.

![Demo](https://cdn.modrinth.com/data/TAlJ7SGo/images/9976364a9e8292582612a41e4773301a7c69f7ba.gif)

## Features
- 🎯 One-key instant TNT minecart detonation
- 🔄 Multiple modes: Burst, Place, Chain, Detonate
- 🎒 Auto-restock from inventory
- 🧠 Smart aim assist
- ⏱️ Configurable cooldown
- 🌍 Multi-language support

## Installation
1. Install [Fabric Loader](https://fabricmc.net/)
2. Install [Fabric API](https://modrinth.com/mod/fabric-api)
3. Install [Cloth Config](https://modrinth.com/mod/cloth-config)
4. (Optional) Install [Mod Menu](https://modrinth.com/mod/modmenu)
5. Drop the mod JAR into your `mods` folder

## Usage
- Press `C` to trigger the current mode
- Press `V` to cycle modes
- Configure via Mod Menu or `config/autotntcart.json`

## Modes
| Mode | Description |
|:---|:---|
| Burst | Shoot arrow, place rail, spawn TNT cart |
| Place | Place rail and cart without shooting |
| Chain | Place a chain of rails |
| Detonate | Detonate an existing TNT cart |
